# Lo de Anita

Web estática independiente en HTML, CSS y JavaScript. Abre `index.html` con Live Server; no necesita instalación ni compilación.

La dirección procede del encargo: Calle Cádiz, 41, 11670 El Bosque, Cádiz, España. El enlace de Google Maps busca esa dirección con el nombre del negocio. No se han añadido datos de contacto, horarios, productos o servicios no proporcionados.

## Privacidad e indexación

No usa analítica, cookies, fuentes remotas ni mapas incrustados. Las fotografías y recursos se sirven localmente. Los enlaces externos solo se abren al pulsarlos. El HTML contiene una única etiqueta `robots` con `noindex, nofollow`. Mantenerla en futuras versiones salvo autorización expresa.

Repositorio: https://github.com/pabloldl/lodeanita. Publicación del código autorizada por el usuario; sin despliegue web.
